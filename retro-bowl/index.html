How To Play

Retro Boll is a fast-paced, arcade-style football game where players take control of a team and aim to score touchdowns while avoiding defenders. The game combines retro graphics with modern gameplay mechanics, offering a nostalgic yet engaging experience. If you're unfamiliar with how to play, check out the game's built-in tutorial for guidance.

The Code

The web version of Retro Bowl is built using MonoGame's WebGL support, enabling C#/MonoGame games to run seamlessly in browsers via WebGL 2.
