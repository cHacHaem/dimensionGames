How To Play

Tag is a fun multiplayer game where players chase each other around a map trying to "tag" one another. Use the arrow keys, WASD, JIL, or FTH to move your character. Tag the another player before time runs out or you lose. Jump through portals and collect power-ups to evade the tagger. Stay quick and keep moving to avoid being tagged!

The Code

Tag is built using the Phaser game framework. Phaser provides a robust set of tools for handling 2D graphics, input, physics, and more.
