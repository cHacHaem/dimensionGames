How To Play

Tunnel Rush is a fast-paced 3D game where you navigate through an endless tunnel filled with obstacles. Use the arrow keys or WASD to steer left and right, avoiding walls and barriers as you speed through the tunnel. The goal is to survive as long as possible. The game gets progressively faster and more challenging, so quick reflexes and sharp focus are key to achieving a high score!

The Code

Tunnel Rush was created using Unity, a powerful and versatile game engine widely used for developing both 2D and 3D games. Unity provides developers with tools to create immersive experiences, including physics simulations, rendering, and scripting capabilities. Learn more about Unity at Unity's official website.
