How To Play

Subway Surfers is an endless runner game where you play as a graffiti artist who is caught tagging a train and must run away from the pursuing inspector and his dog. The objective is to run as far as possible while avoiding obstacles such as trains, barriers, and tunnels. Use the arrow keys to jump, duck, and change lanes. Along the way, you can collect coins and power-ups to help you achieve a higher score. The game features vibrant graphics, smooth controls, and exciting gameplay that keeps players engaged and entertained.

The Code

This version of Subway Surfers was created using Unity, a powerful and versatile game engine widely used for developing both 2D and 3D games. Unity provides developers with tools to create immersive experiences, including physics simulations, rendering, and scripting capabilities. Learn more about Unity at Unity's official website.
