How To Play

Tag Master is a fun, interactive browser game that teaches players how to write and fix broken HTML code. In each level, you're presented with a snippet of HTML that's missing tags, incorrectly nested, or poorly formatted. Your task is to correct the HTML in a text editor so it matches a visual target shown in a live preview. As you progress, the levels get more complex, gradually introducing real-world HTML scenarios like lists, forms, tables, and images. It's a hands-on way to learn HTML by doing — perfect for beginners or anyone looking to sharpen their web development skills.
