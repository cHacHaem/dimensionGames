How To Play

Edge Not Found is a fast-paced browser puzzle-platformer where you guide a block through glitchy, ever-shifting levels full of missing edges and broken geometry. Instead of avoiding errors, you must use them to your advantage, bending incomplete platforms and impossible shapes to reach the goal.

The Code

Edge Not Found was created using JavaScript, HTML, and CSS. JavaScript is used to handle the game's logic, including player movement, collision detection, and level progression. HTML provides the structure of the game interface, while CSS is used for styling and layout to create an engaging visual experience. The combination of these web technologies allows Edge Not Found to run directly in web browsers without the need for additional software or plugins.
