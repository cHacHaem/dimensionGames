How To Play

Site Craft is an interactive browser game that teaches players how to build websites using HTML. In each level, you're given a specific task, such as adding headings, paragraphs, links, images, and more. You write the HTML code in a text editor, and a live preview shows you how your website looks as you build it. As you progress through the levels, the challenges become more complex, gradually introducing real-world HTML scenarios. It's a hands-on way to learn HTML by doing — perfect for beginners or anyone looking to sharpen their web development skills.
