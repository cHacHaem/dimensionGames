How To Play

Use the left and right arrow keys to stay balanced and the up and down keys to accelerate.

The Code

Moto X3M was made using Phaser, a fast, free, and open-source HTML5 game framework. Phaser is widely used for creating 2D games that run in web browsers. It provides features like physics, input handling, and asset management, making game development easier and more efficient. Learn more about Phaser at phaser.io.
