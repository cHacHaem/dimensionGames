How To Play

Use your arrow keys to navigate your ship through the futuristic track, keep up your speed, but avoid hitting the walls or you'll lose your speed and eventually get destroyed. How quick can you complete the course?

The Code

HexGl was built using Three.js and WebGL for rendering 3D graphics in the browser. The game features real-time physics, dynamic lighting, and smooth animations to create an immersive racing experience. The code handles user input, game logic, and rendering to ensure a seamless gameplay experience.
