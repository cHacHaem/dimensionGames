How To Play

Soccer Random is a hilarious and chaotic physics-based soccer game where each player controls a wobbly, unpredictable character. One player uses the Up Arrow to jump and kick, while the other uses W—but that's where the simplicity ends. With every point, the field, players, and ball change in unexpected ways, keeping you on your toes as you bounce, flip, and tumble your way to victory. It's fast, funny, and totally unpredictable!

The Code

Soccer Random was created using Unity, a powerful and versatile game engine widely used for developing both 2D and 3D games. Unity provides developers with tools to create immersive experiences, including physics simulations, rendering, and scripting capabilities. Learn more about Unity at Unity's official website.
