How To Play

Cluster Rush is an exciting game where players navigate through a series of challenging levels by jumping from one moving truck to another. The goal is to reach the end of each level without falling off the trucks or hitting obstacles. Timing and precision are key as the trucks move unpredictably, and players must adapt quickly to the changing environment. Use A and D to move left to right and J to climb and jump from truck to truck. Master your reflexes and conquer the chaos!

The Code

Cluster Rush was created using Unity, a powerful and versatile game engine widely used for developing both 2D and 3D games. Unity provides developers with tools to create immersive experiences, including physics simulations, rendering, and scripting capabilities. Learn more about Unity at Unity's official website.
