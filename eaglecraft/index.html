How To Play

Eaglecraft is a browser-based Minecraft clone that allows you to experience the classic sandbox gameplay directly in your web browser. To play, simply use the WASD keys to move, the mouse to look around, and left-click to break blocks or right-click to place them. You can access your inventory by pressing 'E'. Explore, build, and survive just like in the original Minecraft!

The Code

Eaglercraft is a browser-based version of Minecraft. It uses TeaVM to convert Java code into JavaScript and an OpenGL emulator for graphics, making the game playable in web browsers.
