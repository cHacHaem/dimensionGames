How To Play

Sandboxels is a browser-based falling-sand sandbox where you click or drag to place pixels of different materials—like powders, liquids, gases, plants, animals, and even electricity—onto a canvas and watch them interact. Over 500 elements simulate behaviors such as heat conduction, combustion, density-driven flow, chemical reactions, plant growth, and fire spread.

The Code

Sandboxels utilizes a custom JavaScript engine built atop the HTML5 canvas element. This setup allows for efficient pixel-level rendering and real-time simulation of over 500 unique elements. The game is entirely self-contained, with no external libraries or frameworks, ensuring lightweight performance suitable for modern browsers.
