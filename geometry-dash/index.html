How To Play

Click the screen, use the up arrow key, or press space to make your character jump. Time your jumps to avoid obstacles and gaps in the level. The goal is to reach the end of the level without crashing into any obstacles. Collect coins along the way to complete the challenge.

The Code

This veresion of geometry dash was built entirely with HTML, CSS, and JavaScript, using the Canvas 2D API for graphics and the Web Audio API for music synchronization. Levels are stored as simple data arrays, the game loop handles physics and collision detection, and the illusion of forward movement is achieved by scrolling the world instead of the player. It's a lightweight, browser-native Geometry Dash clone.
