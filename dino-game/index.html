How To Play

Press the spacebar or the up arrow key to make the dinosaur jump. Avoid obstacles like cacti and flying pterodactyls by timing your jumps correctly. Use the down arrow to duck. The game speeds up over time, so stay alert and try to beat your high score!

The Code

This version of the Dino Game was built using HTML, CSS, and JavaScript. It utilizes the Canvas API for rendering graphics and handling animations. The game logic includes obstacle generation, collision detection, and score tracking. The code is designed to be lightweight and efficient, ensuring smooth gameplay in any modern web browser.
