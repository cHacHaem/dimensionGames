How To Play

Untrusted is a meta-JavaScript adventure game where you play as a character trapped inside a JavaScript program. To escape, you must modify the game's code in real-time, using JavaScript to solve puzzles, manipulate the environment, and progress through levels. Each level presents unique challenges that require creative coding solutions, making it an engaging way to learn and practice JavaScript while having fun.
