How To Play

Deadly Decent is an action-packed game where you have to use the arrow keys to navigate your car across various obstacles to make it to the finish of each level. You can upgrade your car to improve its performance and tackle tougher challenges.

The Code

Deadly Decent was created using Unity, a powerful and versatile game engine widely used for developing both 2D and 3D games. Unity provides developers with tools to create immersive experiences, including physics simulations, rendering, and scripting capabilities. Learn more about Unity at Unity's official website.
